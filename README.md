# IPL-AUCTION-MANAGER-2026IPL AUCTION MANAGER 2026

A Java-based console application that simulates an IPL player auction.

🚀 Features

- 10 IPL Teams
- Player Auction Management
- Live Bidding System
- Team Budget Management
- SOLD / UNSOLD Player Status
- Final Auction Summary

💻 Technologies Used

- Java 21
- Object-Oriented Programming (OOPS)

▶️ How to Run

Compile:

javac Main.java

Run:

java Main

🎯 Project Objective

To demonstrate Object-Oriented Programming concepts through a simulated IPL auction system.
